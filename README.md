# Adwitya Trading Journal

A static public trading journal built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Add a trade
Open `trades.js` and copy an existing object. Change the values.

For a chart image:
1. Create an `images` folder.
2. Put your screenshot inside it.
3. Set `image:"images/your-file.jpg"` in the trade object.

## Publish for free with GitHub Pages
1. Create a GitHub account at https://github.com if you don't already have one.
2. Create a new public repository, e.g. `trading-journal`.
3. Upload `index.html`, `style.css`, `app.js`, `trades.js`, and the `images` folder.
4. In the repository go to Settings → Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Choose the `main` branch and `/ (root)`.
7. Save.
8. GitHub will give you a public `github.io` URL.

## Important
The six trades currently in `trades.js` are clearly intended as demo/placeholder data. Replace them with your actual record before publishing.
